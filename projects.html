--- layout: page title: Projects --- # Projects GitHub profile: [https://github.com/SkafteNicki](https://github.com/SkafteNicki) My GitHub profile contains a near-exhaustive list of code that I have developed throughout my years. The following lists the most completed code projects that you may find interesting. --- ## libcpab **Link:** [https://github.com/SkafteNicki/libcpab](https://github.com/SkafteNicki/libcpab) *libcpab* provides a library for working with diffeomorphic transformations in NumPy, TensorFlow, and PyTorch. The library is written to be user-friendly, so you don't have to know the slightest thing about diffeomorphic transformations to get started. The code is designed to work with 1D data (time series), 2D data (images), and 3D data (volumetric images). --- ## ddtn **Link:** [https://github.com/SkafteNicki/ddtn](https://github.com/SkafteNicki/ddtn) Code related to the experiments of our 2018 paper on *Deep Diffeomorphic Transformer Networks* (see publications). The code is written in a combination of C++ and TensorFlow and enables users to easily use the diffeomorphic transformer layer in their own code. --- ## torchplot **Link:** [https://github.com/MachineLearningLifeScience/torchplot](https://github.com/MachineLearningLifeScience/torchplot) Have you ever encountered the problem of forgetting to call `.cpu().detach().numpy()` when you are trying to plot something from PyTorch in `matplotlib.pyplot`? Then `torchplot` is something for you. It is a simple plug-in replacement for your standard `matplotlib.pyplot` that makes sure to transfer, detach, and convert any `torch.tensor` before calling the actual plot function. --- ## Other Notable Projects ### john Reliable training and estimation of variance networks - [GitHub](https://github.com/SkafteNicki/john) ### unsuper Explicit Disentanglement of Appearance and Perspective - [GitHub](https://github.com/SkafteNicki/unsuper) ### meaningful-protein-representations What is a meaningful representation of protein sequences? - [GitHub](https://github.com/MachineLearningLifeScience/meaningful-protein-representations)
